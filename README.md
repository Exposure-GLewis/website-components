# Website Component Library

A standalone public GitHub component repository starter, separate from the VS Code extension source.

Library version 1.1.0 contains:

- Layouts: Three Column Layout.
- Heroes: Hero — Video Background, Hero — Image Fader, Hero — Single Background Image.

Upload the CONTENTS of this directory to the root of a separate public GitHub repository. The manifest.json file must be at the repository root. Do not upload only the ZIP file or wrap these files in an extra starter directory.

In VS Code run Component Library: Add Repository, supply the repository URL and branch/tag, choose a display name and sync schedule, then run Sync Repository and Select Repository. Repository management uses the componentLibrary.repositories user setting. The extension downloads read-only and never commits or pushes.

Make library edits in your normal GitHub workflow. Update component versions for changed components and libraryVersion for a library release. After committing, sync the extension. An installed cache works offline.

Use the H/C/J buttons to insert each part into your selected editor. CSS/JS files and references are not installed automatically; create and link those files manually. See HERO-IMPORT.md for hero usage, required media, preserved source blocks and adaptation notes. Video files are not included; the images use external placeholder URLs until you replace them.

Original ASP.NET source files were not changed. Only the heros folder was used for this import. No imported JavaScript was executed.
