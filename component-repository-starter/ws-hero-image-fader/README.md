# Hero — Image Fader

Version 1.0.0 · Category: Heroes

Three-image background slideshow with pause/play and reduced-motion support. Link CSS and JavaScript manually; replace the external placeholder images for offline website use.

Use H/C/J to insert the HTML/CSS/JavaScript part at your active editor cursor. Create the CSS/JS destination files and link them manually. One possible asset folder is assets/components/ws-hero-image-fader/ folder. Link them manually:

```html
<link rel="stylesheet" href="assets/components/ws-hero-image-fader/style.css">

<script src="assets/components/ws-hero-image-fader/script.js" defer></script>
```

Include the stylesheet/script once per page; multiple instances of template.html can share them. Save and refresh the website after inserting. Replace placeholder image/video paths with your own media. The component does not require ASP.NET or a website framework.

The original/ files preserve the source page's decoded code blocks for reference. The active files have component-specific classes, scoped initialization, and local support styles. JavaScript was syntax-checked without execution; browser behavior is not verified.
